# love / money / career (LMC) 트랙 진행 기록

EN 521개의 love / money / career 세 필드를 다루는 트랙이다. 이 세 필드는
심화 15개, X111 트랙 31개, manifestation 배치 1~14 어디에서도 작업
대상이 아니었다(전부 "범위 밖"). 그래서 meaning·manifestation을 새로 쓴
페이지에서도 이 세 필드는 옛 논지와 옛 골격을 그대로 갖고 있었다.

참조. 이 파일은 진단·계획·진행 기록만 담는다.**

### 7111 manifestation 처리

- **옛 문장**: "There's usually one specific realization underneath
  whatever momentum you're riding when 7111 shows up — not a vague sense
  that things are going well, but a single insight that actually started
  it. Have you named that insight, specifically, or just kept riding the
  momentum without ever tracing it back to its source?"
  - 통찰이 있다고 단언한다.
  - X111 금지 어휘 momentum과 "tracing it back"이 들어 있다.
- **새 문장**: "Before you ask this current push to carry a new want, find
  out what fuels it. 7111 doesn't guarantee a realization sits beneath it —
  sometimes one does, sometimes good conditions have been doing the
  lifting. If you can name an insight, build your next ask on it
  deliberately; if you can't, let the want rest on what's visibly true and
  skip inventing a cause to justify it."
- **정합성**:
  - meaning: "insist하지 않고 확인했는지 묻는다"
  - FAQ3·4: 통찰이 없을 수도 있다
  - action: 한 문장으로 말해보고, 안 나오면 그것도 정보다
  - 새 manifestation은 이 셋과 같은 방향이다. 규칙 K는 0건이다.
  - FAQ1의 "one plain sentence" 표현은 피했다.
  - 1차 초안에 "momentum"이 들어가 있어 작성 직후 교체했다.

## 2단계 배치 크기 판단 근거

- 1단계는 60칸 + manifestation 1칸이었다. 재작성은 묶음 단계 17칸,
  통합 단계 12칸, 다듬기 2칸, 합계 약 31칸(약 50%)이다.
- 페이지 안 4칸 복제는 배정을 먼저 하면 **재작성을 유발하지 않았다
  (0회)**. 4칸 구조 자체는 배치 크기를 줄일 이유가 아니다.
- 비용의 대부분은 **규칙 K(페이지당 약 0.9칸)**와 **통합 검사(전체
  모집단에서만 보이는 페이지 간 중복·서법 쏠림)**다. 둘 다 칸 수에
  비례해 늘어난다.
- 2단계는 페이지당 manifestation까지 5칸이다.
  - 10페이지 = 50칸으로, 이번 1단계(61칸)와 비슷한 규모다.
  - 20페이지 = 100칸이 되어, 정규 배치4의 "20개 동시 작성 → 대량 충돌"
    전례가 재현될 위험이 크다.
- **결론: 2단계 배치 크기는 10페이지로 권장한다.** 묶음은 5페이지 × 2
  묶음 + 통합 검사로 한다. 서법은 페이지당 같은 것 2칸 이하로 배정에
  추가한다.
- 주의: 정규 배치 잔여 페이지는 대부분 템플릿기(C) 페이지라, meaning이
  LMC와 이미 같은 문장을 공유하는 경우가 많다(진단: LMC~meaning 3-gram
  3개 이상 공유 213페이지). X111 페이지보다 규칙 K 위반률이 높을 수 있다.
  첫 2배치의 실측으로 10페이지가 맞는지 다시 판단한다.
