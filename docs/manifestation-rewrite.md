# manifestation 필드 재작성 진행 기록

## 배경

### 담화 규칙 (배치 1 자가검증에서 확정, 배치 3에서 절대값 상한 폐기 후 비율제로 수정)
어휘를 바꿔도 결말 방식이 같으면 같은 글이다. n-gram 검사로 안 잡히는
담화 수준 반복이므로 별도로 관리한다.
- 대비형("X, not Y") 결말: 배치당 5개 이하 (유지)
- ~~누적 40개 기준 15개 초과 금지~~ → 절대값 상한 폐기.
  40개 시점에 이미 15개 도달로 남은 24배치 동안 대비형을 전혀
  못 쓰게 되는 인위적 편향이 발생해 비율제로 교체:
  - **누적 대비형 비율 30% 이하를 목표로 한다**
  - 현재(배치1+2, 40개 중 15개=37.5%)로 목표 초과 상태
  - 배치 3~6에서 대비형을 배치당 2개 이하로 써서 비율을 낮춘다
  - 120개 시점(배치 6)에 30% 이하 도달을 목표로 한다
  - 30% 도달 후에는 "배치당 5개 이하" 규칙만 적용한다
- 결과형/근거형/행동형/조건형/질문형 각각 배치당 최대 5개

### 문장 형태 3축 (배치 3에서 확정 — "주절 주어" 폐기, "근거의 출처" 도입)
"주절 주어"는 명령문에서 첫어절 축과 1:1 중복이라 배치 3에서 폐기.
현재 3축: 첫어절 품사 / 근거의 출처 / 결말 방식.

**규칙 발견 부작용**: 배치1은 명령형 오프너(10/20)로, 배치2는 숫자시작
오프너(13/20)로 각각 몰렸다 — "이전 편중을 피하라"는 규칙 자체가
매번 새 획일성을 만든 것. 그래서 배치 3부터는 금지가 아니라
**목표 분포**로 관리한다.

**오프너 목표 분포** (배치당, 6개 초과 금지):
- 동사(명령) 4 / 숫자 시작 4 / 명사구 3 / 조건절 3 / 관계절 3 / 전치사구·부사구 3
- 배치 3 실측: 동사4 / 숫자4 / 관계절3 / 명사구3 / 전치사구3 / 조건절3 (목표 정확히 달성)

**근거의 출처 목표** (배치당):

- 독자의 상황: 6개 이상
- 비교 대상: 5개 이상 (가장 안 쓰이던 축 — 우선 확보)
- 근거 없음: 2개 이하

- 누적(60개): 숫자자체23(38.3%) / 독자상황25(41.7%) / 비교대상9(15%) / 근거없음3(5%)

### whatever 억제 + 조건·관계 도입 다양화 (배치 4에서 확정)
누적 60개 시점 조건·관계 도입부 실사용에서 **"whatever"가 18/60(30%)**로
편중 확인 — n-gram 검사로는 안 잡히는 또 다른 층위의 획일성.
"이전 편중을 피하라"는 규칙이 매번 새 편중을 낳는다는 패턴이 세 번째로
확인됨(배치1 명령형→배치2 숫자시작→배치3 어느정도 균형→배치4에서 whatever
과다 발견).

- **whatever 사용: 배치당 2개 이하**
- 조건·관계 도입은 아래 5개 형태로 분산 (한 형태 4개 초과 금지):
  if/when/once/unless/as long as / 분사구문(-ing) / 명사구+that절 /
  도치·삽입구 / 조건 없이 단언
- 배치 4 실측 whatever: 1/20 (7777만 사용, 누적 80개 기준 20회 —
  절대량은 여전히 많으나 배치 4 자체는 억제 성공)
- 배치 4 조건·관계 도입 형태: if(1)/when(1)/once(1)/unless(1) — 4개 형태
  각 1회씩 고르게 분산, 분사구문 1(999), 명사구+that절 1(4455),
  삽입구 1(2552), 관계절-whichever 2(454, 2111) — "whatever" 대신
  "whichever"로 대체해 조건 도입 자체를 다양화

### 연결구 회피 규칙 (배치 4에서 확정)
누적 배치에서 2회 이상 반복된 연결구는 완전 금지가 아니라
**배치당 1회 이하**로 관리한다. 배치 4 대상: rather than / right now /
a single / not just / instead of / is what / is already / more than /
pointing at / depends on whether / isn't asking / comes down to.

isn't asking(1, 2111) — 나머지 전부 0회. 규칙대로 작동함.

### 미수정분 수치 정정
"남은 430개"는 심화 1~2차(10개) 완료 시점의 스냅샷으로 확인됨.
심화 3차(5개: 1212/0000/11111/9/0101)가 이후 완료되어 반영이 안 된
수치였다. 정확한 수치: 520개 전체 - 80개(배치1~4 재작성) = **440개**
(심화15+형제14 포함). 이후 모든 배치 기록은 440 기준으로 통일한다.

### specific 계열 반복 문제 (배치5에서 별도 항목으로 확정)

발생하는 구조적 반복이며, 완전히 제거하면 원문 내용을 훼손한다.

- 묶음1(4,322,6666,1221,789): 1차 초안 충돌 다수 → 국지적 재작성 3회 반복
- 묶음2(65,118,9992,3443,8118): 충돌 다수(초안 길이도 과다) → 재작성 4회 반복
- 묶음3(733,3111,5665,3355,345): 충돌 다수 → 재작성 3회 반복
- 묶음4(2222,0505,6060,1515,0333): 충돌 다수(교차 묶음 포함) → 재작성 3회 반복

**효과 평가**: 재작성이 "해당 묶음 5개 이내"로 항상 국한되었고,
이전 묶음이나 누적 80개까지 다시 손댄 적은 0회. 배치4처럼 20개
전체를 다시 쓰는 사태는 발생하지 않았다 — 분할 방식은 재작성
범위를 1/4로 줄이는 목적을 달성했다. 다만 묶음당 반복 재작성
횟수(3~4회) 자체는 배치4의 충돌 건수 증가 추세와 무관하지 않게
여전히 높았다 — 즉 "충돌이 발생하는 총량"은 줄지 않았고,
"충돌 1건당 다시 써야 하는 범위"만 줄었다.
**배치 6부터도 5개씩 분할 작성 방식을 계속 적용한다.**
