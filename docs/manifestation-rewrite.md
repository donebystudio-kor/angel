# manifestation 필드 재작성 진행 기록

## 배경

### 담화 규칙 (배치 1 자가검증에서 확정, 배치 3에서 절대값 상한 폐기 후 비율제로 수정)
어휘를 바꿔도 결말 방식이 같으면 같은 글이다. n-gram 검사로 안 잡히는
담화 수준 반복이므로 별도로 관리한다.
- 대비형("X, not Y") 결말: 배치당 5개 이하 (유지)
- ~~누적 40개 기준 15개 초과 금지~~ → 절대값 상한 폐기.
  40개 시점에 이미 15개 도달로 남은 24배치 동안 대비형을 전혀
  못 쓰게 되는 인위적 편향이 발생해 비율제로 교체:
  - **누적 대비형 비율 30% 이하를 목표로 한다**
  - 현재(배치1+2, 40개 중 15개=37.5%)로 목표 초과 상태
  - 배치 3~6에서 대비형을 배치당 2개 이하로 써서 비율을 낮춘다
  - 120개 시점(배치 6)에 30% 이하 도달을 목표로 한다
  - 30% 도달 후에는 "배치당 5개 이하" 규칙만 적용한다
- 결과형/근거형/행동형/조건형/질문형 각각 배치당 최대 5개

### 문장 형태 3축 (배치 3에서 확정 — "주절 주어" 폐기, "근거의 출처" 도입)
"주절 주어"는 명령문에서 첫어절 축과 1:1 중복이라 배치 3에서 폐기.
현재 3축: 첫어절 품사 / 근거의 출처 / 결말 방식.

**규칙 발견 부작용**: 배치1은 명령형 오프너(10/20)로, 배치2는 숫자시작
오프너(13/20)로 각각 몰렸다 — "이전 편중을 피하라"는 규칙 자체가
매번 새 획일성을 만든 것. 그래서 배치 3부터는 금지가 아니라
**목표 분포**로 관리한다.

**오프너 목표 분포** (배치당, 6개 초과 금지):
- 동사(명령) 4 / 숫자 시작 4 / 명사구 3 / 조건절 3 / 관계절 3 / 전치사구·부사구 3
- 배치 3 실측: 동사4 / 숫자4 / 관계절3 / 명사구3 / 전치사구3 / 조건절3 (목표 정확히 달성)

**근거의 출처 목표** (배치당):

- 독자의 상황: 6개 이상
- 비교 대상: 5개 이상 (가장 안 쓰이던 축 — 우선 확보)
- 근거 없음: 2개 이하

- 누적(60개): 숫자자체23(38.3%) / 독자상황25(41.7%) / 비교대상9(15%) / 근거없음3(5%)

### whatever 억제 + 조건·관계 도입 다양화 (배치 4에서 확정)
누적 60개 시점 조건·관계 도입부 실사용에서 **"whatever"가 18/60(30%)**로
편중 확인 — n-gram 검사로는 안 잡히는 또 다른 층위의 획일성.
"이전 편중을 피하라"는 규칙이 매번 새 편중을 낳는다는 패턴이 세 번째로
확인됨(배치1 명령형→배치2 숫자시작→배치3 어느정도 균형→배치4에서 whatever
과다 발견).

- **whatever 사용: 배치당 2개 이하**
- 조건·관계 도입은 아래 5개 형태로 분산 (한 형태 4개 초과 금지):
  if/when/once/unless/as long as / 분사구문(-ing) / 명사구+that절 /
  도치·삽입구 / 조건 없이 단언
- 배치 4 실측 whatever: 1/20 (7777만 사용, 누적 80개 기준 20회 —
  절대량은 여전히 많으나 배치 4 자체는 억제 성공)
- 배치 4 조건·관계 도입 형태: if(1)/when(1)/once(1)/unless(1) — 4개 형태
  각 1회씩 고르게 분산, 분사구문 1(999), 명사구+that절 1(4455),
  삽입구 1(2552), 관계절-whichever 2(454, 2111) — "whatever" 대신
  "whichever"로 대체해 조건 도입 자체를 다양화

### 연결구 회피 규칙 (배치 4에서 확정)
누적 배치에서 2회 이상 반복된 연결구는 완전 금지가 아니라
**배치당 1회 이하**로 관리한다. 배치 4 대상: rather than / right now /
a single / not just / instead of / is what / is already / more than /
pointing at / depends on whether / isn't asking / comes down to.

isn't asking(1, 2111) — 나머지 전부 0회. 규칙대로 작동함.

### 초안 충돌 사전 회피
배치 3에서 60개 규모가 되자 초안에서 일반 연결구 충돌이 대거 발생해
20개 중 대부분을 재작성했다. 규모가 커질수록 심해질 것이다.

배치 4부터는 작성 전에 "이미 쓰인 연결구 목록"을 먼저 추출해서
회피 목록으로 삼는다. 재작성 비용을 초안 단계로 옮기는 것이다.

현재까지 확인된 연결구 (재사용 주의):
- depends on whether
- is pointing at
- rather than (누적 8회)
- not just / instead of / right now

### 비교 대상 근거 부족
누적 60개 중 9개(15%)로 여전히 최소.
배치 4도 5개 이상 배정할 것.

### X111 계열 완료 상황
9111(배치1, 결과형) / 7111(배치2, 질문형) / 8111(배치3, 근거형·반대명제)
남은 X111 계열이 있으면 앞의 셋과 또 다른 논지가 필요하다.
배치 4 조사에서 잔여 여부를 확인할 것.

### 배치 4/26 — 완료
대상 20개: 155, 511, 41, 8000, 454, 5225, 8778, 2552, 2111, 999,
7777, 1717, 2424, 0888, 4455, 5522, 0303, 432, 765, 7
(제외: 심화 10 + 배치1·2·3의 60개 + 형제 참조 9)

**연결구 사전 추출**: 누적 60개에서 2회 이상 쓰인 연결구
(rather than 8 / right now 8 / a single 7 / not just 5 / instead of 5 /
is what 5 / is already 4 / more than 4 / pointing at 3 / depends on
whether 2 / isn't asking 2 / comes down to 1)를 배치당 1회 이하로
관리하는 규칙 신설. 조건 도입부 실사용에서 **whatever가 18/60(30%)**로
편중된 것을 확인 — n-gram으로 안 잡히는 세 번째 층위의 새 획일성.

**X111 계열 잔여 확인**: 9111·7111·8111 외에 **2111, 3111, 5111, 6111
4개**가 동일 골격("honoring [X] as spark for new energy")임을 확인.
한 배치에 다 넣으면 배치 내부 뭉치가 재발하므로 이번엔 **2111 하나만**
선정, 3111·5111·6111은 배치5~6으로 이월.

**2111**: 9111(결과, "완결된 챕터가 원천")·7111(질문, "구체적 통찰
추적")·8111(근거, "사건 추적 불필요")을 다시 읽고, 넷 다 "지목 대상이
무엇인가"만 다뤄 결말만 다른 같은 글이 될 위험 확인. 2111은
**지목 대상 자체를 전환**해 "어떤 감정/사건이 아니라 어떤 사람이
원천인가"(조건형)로 감. spark/ignite/momentum/wave 미사용.

**5225/5522 배치 내부 충돌**: 조사에서 세운 차별화 계획대로
5225=조건절(when)+독자상황+행동형, 5522=전치사구+비교대상+질문형으로
갈랐고, 5522가 5225를 가볍게 언급하되("같은 조용한 지원은 아니다")
5522 자체의 질문과 조언은 5225 없이도 완결되게 처리.

결과:
- whatever 배치4 내 1회(7777) — 목표(2개 이하) 충족
- 연결구 회피 목표(1회 이하) 전부 충족: a single(1717) / instead of(155) /
  more than(8000) / isn't asking(2111) 각 1회, 나머지 0회
- 조건·관계 도입 형태: if/when/once/unless 각 1회, 분사구문 1(999),
  명사구+that절 1(4455), 삽입구 1(2552), 관계절(whichever) 2(454,2111)
  — 다양하게 분산, 특정 형태 4개 초과 없음
- 결말: 근거5/행동4/결과3/대비2/질문3/조건3 — 대비 4개 이하 권장 충족
- 근거출처: 독자상황8/비교대상7/숫자자체5/근거없음0 — 목표 전부 충족
- 누적(80개) 대비형 19개(23.8%) — 목표 30% 대비 여유 확보
- **초안 단계에서 다수 충돌 발생 → 재작성으로 전량 해소, 최종본
  80개 3-gram 교차 0건, 이전배치(1~3) 4-gram 재사용 0건**
- 2111 4중 대조: 9111·7111·8111과 지목 대상 자체가 다름 확인
- 5225/5522 독립성 확인
- 오프너(80개 기준) 중복 0건
- 금지 표현(누적 전체) 0건

## 배치 5 과제 (추가)

### 초안 충돌 증가 추세 — 구조적 문제
배치 3: 다수 / 배치 4: 43건
규모에 비례해 증가 중. 160개 시점(배치 8)에는 100건 이상 예상.
연결구 회피 목록으로는 막을 수 없다. 목록에 없는 표현이 겹치기 때문.

배치 5부터 대응:
- 작성 순서를 바꾼다. 20개를 한 번에 쓰지 말고
  5개씩 4묶음으로 나눠 쓴다
- 각 묶음을 쓴 직후 이전 묶음 및 누적분과 3-gram 대조
- 충돌 시 그 묶음만 재작성. 20개 전체를 다시 쓰지 않는다
- 목적: 재작성 범위를 1/4로 줄이는 것

### 재작성 후 재측정 (필수 체크리스트)
배치 4에서 충돌 재작성이 길이를 흔들어 3개가 목표 구간을 이탈했다.
재작성한 항목은 반드시 길이를 다시 재고 목표 구간을 확인한다.
재측정 없이 자가검증을 통과시키지 않는다.
