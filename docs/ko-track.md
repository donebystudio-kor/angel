# 한국어 X111/111X 트랙 진행 기록

한국어 코퍼스(angels-core.ts + angels-batch1~13.ts, 521개)는 영어와 독립적으로
작성된 데이터이며, 영어 X111·111X 트랙에서 발견된 것과 동일한 종류의 골격
중복 문제가 있음을 전수 진단(2026-09)에서 확인했다. 이 문서는 그중 X111
8개(2111~9111) + 111X 8개(1112~1119) = 16개를 다룬 첫 트랙의 기록이다.

**금지 표현·연결구 등 공통 규칙은 `forbidden-expressions.md`, 이식한 관계 축의
원 설계는 `x111-track.md`(영어 트랙 1·2) 참조.**

## 한국어 특유 문제 — 문장 수·종결어미 (영어에는 없던 층위)

어절 골격을 없애도 **문장 개수와 종결어미가 같으면 리듬이 똑같아 반복감이
남는다**는 점을 이번에 확인했다. 재작성 시 필드별 문장 수를 페이지마다
다르게 배정하고, 종결 형태도 흩었다.

### 종결어미 배분 (meaning 마지막 문장 기준)

사이트 전체 문체("~해요"체)와 어긋나지 않게, "~해요/예요"는 유지하되
**문장 형태**를 흩었다.

| 형태 | 번호 | 개수 |
|---|---|---|
| 평서 (~해요/예요/거예요) | 2111, 4111, 1112, 1114, 1116, 1118, 1119 | 7 |
| 청유 (~보세요) | 3111, 7111, 1113, 1117 | 4 |
| 의문 (~일까요?/~않을까요?) | 5111, 1115 | 2 |
| 명사형 종결 (~것이에요/~셈이에요/~일이에요) | 6111, 8111, 9111 | 3 |

전부 상한(6개) 이내. 의문형은 축의 성격(5111 순서문제제기, 1115 고갈의
불확실성)과 자연스럽게 맞는 곳에만 배정 — 억지로 늘리지 않았다.

## FAQ 답변 논증 구조 (Q2, 8쌍)

| 짝 | 논증 구조 |

| 3111 ↔ 1113 | 순서 뒤집기("거꾸로 보면") |
| 4111 ↔ 1114 | 공통점 인정 후 차이점 분리(속도) |

| 6111 ↔ 1116 | 정도차·탄력성 비유 |

| 8111 ↔ 1118 | 질문 재구성("무엇이 원인인가"보다 "모양이 어떤가") |
| 9111 ↔ 1119 | 인정 후 확장("~도 맞다, 다만 한 걸음 더") |

수정** — 나머지 15개는 재확인 결과 전부 정확한 짝이었음.

## 한국어 double 카테고리 34개 재작성 (완료)

### 대상과 구조 분류
`category: "double"` 34개 전체. 진단에서 26/34(76%)가 골격 중복으로 확인됐으나
실제 재조사 결과 **31/34(91%)**가 두 개의 서로 다른 골격에 걸려 있었다(아래
"예상 못 한 발견" 참조).

- **AABB(XXYY) 25개**: 1133,1166,1177,1188,1199,2211,2233,2244,2255,2266,
  3311,3322,3344,3355,3366,4411,4422,4433,4455,4466,5511,5522,5533,5544,5566
- **ABAB(XYXY, 전부 0과 짝) 9개**: 0202,0303,0404,0505,0606,0909,0808,0101,0707
- 기타 형태 0개 — 34개가 정확히 두 구조로 나뉨

AABB 25개 중 7쌍(14개)은 같은 두 자릿수의 순서만 반대인 "형제"가 존재한다
(1133↔3311, 2233↔3322, 2244↔4422, 2255↔5522, 3344↔4433, 3355↔5533,
4455↔5544). 이 7쌍은 "순서가 바뀌면 어느 쪽이 주도하는가"로 차별화했다.
나머지 11개(형제 없음)는 독립적인 관계축을 배정했다.

한국어 X111/111X 16개와의 중복 없음(구조 자체가 다름). 영어 심화 15개 중
1177·0101이 대응 번호이나 참고만 하고 배제하지 않았다.

### 작성 절차 — 계획과 실제의 차이
계획은 "6~7개씩 5묶음, 묶음마다 작성→검증→다음 묶음"이었으나, **실제로는
5묶음을 전부 초안 작성한 뒤 34개 전체를 한 번에 전수 대조했다.** 이유:
7개 단위 검사로는 묶음을 넘나드는 골격 재사용(예: AABB "역방향" 10개, 0X0X
"두 번 오는" 6개)을 못 잡는다는 걸 1차 검사에서 확인했기 때문. 이 판단은
"예상 못 한 발견" 항목 참조.

### 초안에서 걸린 위반과 조치 (전부 나열)

**1차 검사 (금지 표현 + 문장 수 + 종결어미 + 3-어절)**

### 예상 못 한 발견

- **ABAB의 골격은 첫 문장이 아니라 문단 전체의 수사적 구조였다.** mirror
  트랙에서 확립한 "오프너만 고치면 된다"는 전제가 이번엔 안 맞았다 —
  같은 "mixed" 카테고리 안에서도 그룹마다 골격의 범위가 다르다는 것을
  확인했다. 앞으로 mixed의 다른 그룹(ABC·ABB·AB)에 착수할 때도 오프너
  범위인지 전체 범위인지 매번 전문을 읽고 재판단해야 한다.
- **FAQ Q1이 완전히 동일한 질문이었다** — 트랙 2·batch5a에서는 Q1이
  전부 자연스럽게 달랐는데, ABAB는 "[N]을 자주 보는데 무슨 뜻인가요?"가
  7/7 리터럴하게 같았다. 이 사이트의 FAQ Q1 관용구 자체가 golgyeok
  대상이 될 수 있다는 새로운 사례.
- **spiritual 필드에서 규칙 E가 다시 재현됐다** — "~라고 여기고
  있었다면, [반복어]하는 시기예요"라는 조건문 틀을 4개 항목에 무의식적으로
  재사용했다. 골격을 없애려고 쓴 새 문장이 스스로 골격이 되는 패턴이
  네 번째로 확인됨(트랙 2, double, 이번 배치까지 최소 3회 자체 재발 +
  최초 발견 1회).
- **범위 밖 필드가 새 축과 충돌할 수 있다는 걸 이번에 처음으로 명시적으로
  계산해봤다** — batch5a는 우연히 충돌이 없었지만, 이번엔 3030·7070·
  4040에서 경미한 충돌이 실제로 발생했다. 새 축을 정할 때 out-of-scope
  필드의 기존 주제와의 궁합도 사전에 확인하는 절차가 필요하다는 교훈.

## mixed 나머지 그룹 착수 시 필수 절차 (ABAB에서 확인, forbidden-expressions.md 규칙 H·I)

mirror에서는 "오프너만 고치면 된다"가 통했다. 그런데 같은 배치의 ABAB와
AAB조차 범위가 달랐다 — ABAB는 골격이 문단 전체 수사 구조(정의 →
"사건 아닌 흐름" 대조 → 조건문 → 결론)였고 spiritual 2문장·action
1문장·FAQ Q1까지 동일해 전체를 다시 써야 했다. AAB는 spiritual/action/
FAQ가 이미 달라 첫 문장만 고치는 게 맞았다. **같은 배치 안에서도
그룹마다 범위가 다르다.**

**남은 그룹(ABA 13 / ABC 33 / ABB 81 / AB 81)착수 전 반드시:**
1. 전문(모든 필드)을 읽고 판단한다 — 골격이 첫 문장에만 있는가, 문단
   전체가 같은 수사 구조를 공유하는가, spiritual·action·FAQ까지
   굳어 있는가.
2. FAQ Q1도 다양화 대상에 포함한다 — "[N]을 자주 보는데 무슨 뜻인가요?"
   같은 사이트 공통 관용구가 그룹 내에서 반복되면 그 자체로 골격이 된다
   (ABAB에서 6060·9090이 이걸로 충돌).
3. 필드 단위로도 틀 검사를 한다 — meaning뿐 아니라 spiritual·action·
   FAQ 각각 따로 뽑아 확인한다(규칙 E가 spiritual 필드에서 세 번째로
   재발한 전례).
4. 판단 근거를 작업 보고에 포함한다 — 이전 그룹의 "오프너만"이라는
   전례를 다음 그룹에 그대로 적용하지 마라.
