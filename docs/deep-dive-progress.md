# 심화 보강 작업 진행 기록

manifestation 필드 재작성(`manifestation-rewrite.md`)과는 별도 트랙. EN 페이지
소수(5개씩)를 골라 structure/distinction/context/misconception/origin/
ambiguity 6개 필드를 신규로 채우는 작업.

**금지 표현·오프너 패턴·비유 재사용 규칙은 `forbidden-expressions.md` 참조.
이 파일은 진행 상황·완료 목록·작업 원칙만 담는다.**

## 작업 종료 (15개에서 종료 — 4차 확대 안 함)

심화 보강 작업은 **15개(1~3차)에서 종료한다.** 4차 조사에서 구조 풀과
축 풀이 동시에 고갈됐음이 확인됐다.

**구조 풀**: 13개 사용, 신규 확인 1개(이중+이중, XXYY — 예: 1166).
기각된 후보와 사유:
- 등간격 산술수열(예: 2468) — 연속시퀀스(간격1)의 변형일 뿐, 근본적으로
  같은 구조
- 자릿수합 환원 vs 조합유지 — 어떤 숫자가 이 퍼즐에 적합한지 정할
  기준이 없어 억지 배정 위험
- 4~5자리 단일반복(1111, 2222 등) — manifestation 배치나 5자리반복
  카테고리로 이미 소진
- 시퀀스/팔린드롬/블록반복의 변형들 — 뜯어보면 결국 기존 13개 중
  하나로 환원됨

**축 풀**: 23개 소진(심화 15 + X111 트랙 8). 신규 후보 5개 전부 기존
축과 구분이 불확실:
- 가역성 vs 비가역성 ← 해소vs미해소(1차)와 겹침
- 양적축적 vs 질적전환 ← 돌파형vs수렴형(3차)과 인접
- 내부기준 vs 외부기준 ← 독립트리거vs부착(2차)과 겹침
- 선택가능 vs 불가피
- 단일경로 vs 복수경로 ← ambiguity 필드 자체의 기능과 겹침

**판단**: 구조 풀과 축 풀이 동시에 고갈된 것은 우연이 아니라 아래
"논증 구조 수렴 문제"에서 이미 경고한 한계에 실제로 도달했다는 신호다.
이름만 바꾼 같은 축으로 확장하면 manifestation 448개가 만들어진 경로
(같은 골격이 반복 재생산되는 경로)를 심화 필드에서 그대로 반복하게
된다. 억지로 채우지 않고 고갈을 정확히 보고하는 쪽을 택한다.

### 재개 조건
아래 중 하나가 충족되면 재검토한다.
- 사이트에 새로운 구조의 숫자가 추가되는 경우
- 기존 6개 필드와 다른 성격의 신규 필드를 설계하는 경우
- 심화 15개의 순위가 실측으로 개선되어 확대 가치가 입증되는 경우

현재 시점에서는 확대하지 않는다.

### 남은 관련 작업
- 심화 15개 측정: 배포 후 3~4주 시점에 검색 순위 변화 확인
- 9111 spiritual에 남은 골격 문구 정리 (`x111-track.md` 참조 — X111
  트랙 4 완료 후 일괄 정리 예정)

## 논증 구조 수렴 문제
6개 필드 전부 1차·2차에서 100% 수렴했음이 3차 조사에서 확인됨.
필드 정의가 논증 구조를 강제하는 구조적 문제 — manifestation
448개 수렴과 같은 종류의 문제가 심화 필드에서도 나타난 것.
3차에서 필드별 논증 구조를 페이지마다 다르게 배정해 해소했으나,
20~30개 이상 확대 시 재수렴 불가피.
**심화 작업은 소수 정예로 유지한다. 대량 확대 금지.**

이 예측은 4차 조사에서 실제로 확인됐다 — 위 "작업 종료" 항목 참조.
