# 심화 보강 작업 진행 기록

manifestation 필드 재작성(`manifestation-rewrite.md`)과는 별도 트랙. EN 페이지
소수(5개씩)를 골라 structure/distinction/context/misconception/origin/
ambiguity 6개 필드를 신규로 채우는 작업.

**금지 표현·오프너 패턴·비유 재사용 규칙은 `forbidden-expressions.md` 참조.
이 파일은 진행 상황·완료 목록·작업 원칙만 담는다.**

## 논증 구조 수렴 문제
6개 필드 전부 1차·2차에서 100% 수렴했음이 3차 조사에서 확인됨.
필드 정의가 논증 구조를 강제하는 구조적 문제 — manifestation
448개 수렴과 같은 종류의 문제가 심화 필드에서도 나타난 것.
3차에서 필드별 논증 구조를 페이지마다 다르게 배정해 해소했으나,
20~30개 이상 확대 시 재수렴 불가피.
**심화 작업은 소수 정예로 유지한다. 대량 확대 금지.**

- 페이지마다 다른 사실을 근거로 쓴다
- 사용된 근거: 0의 자릿값 부재(0000) / 반복횟수 무전통(11111) /
  9의 배수 자릿수합 수렴(9, 산술적 사실)

## 필드 비우기 원칙
채울 내용이 없으면 비운다. 9는 단일 숫자라 structure를 비웠다.
렌더링 게이트는 "6개 필드 중 하나라도 존재"로 되어 있어
일부만 있어도 정상 렌더링된다. (3차에서 수정 — 이전에는
`angel.structure` 단일 조건이라 9처럼 structure가 없는 페이지는
나머지 필드가 있어도 전혀 렌더링되지 않는 버그가 있었음.
`src/pages/en/number/[number].astro`에서 게이트 조건 수정)
