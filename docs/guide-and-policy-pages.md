# 가이드·정책 페이지 (About/Contact/Privacy/Guide) 작업 기록

`/guide/*`, `/about`, `/contact`, `/privacy` 등 521개 숫자 페이지 밖의
사이트 공통 페이지를 다루는 기록이다. manifestation·X111 등 숫자 데이터
재작성 트랙과는 별개 트랙이므로 여기서 따로 관리한다.

## 미해결 사항

### KO 가이드 문체 혼재 (2026-09-20 기록, 미해결)

`/guide/what-is-angel-number`, `/guide/how-to-find-angel-number`,
`/guide/angel-number-and-love` 3개는 원래부터 합쇼체(-입니다/-습니다)와
해요체(-하세요 등 권유형)가 섞여 있었다.

2026-09 톤 조정 작업(About/Contact 신설 + 단정적 신비주의 서술 완화)에서
**손댄 문장만 해요체로 맞췄다** — 완화 대상이 아니었던 문장은 원래 톤을
유지하라는 지시에 따라 합쇼체 그대로 뒀다. 그 결과 같은 페이지 안에서
**조정된 문장은 해요체, 손대지 않은 문장은 합쇼체**로 섞여 있는 상태가
됐다 — 혼재를 없앤 게 아니라 오히려 더 눈에 띄게 만들었다.

**우선순위 낮음으로 보류한다.** 근거:
- 실제 유입은 `/guide/*`가 아니라 홈(`/`)이 대부분이다(GA4 28일 기준,
  `guide-and-policy-audit` 조사에서 확인 — 조회수 1위 573은 홈페이지였고
  `/guide/*` 개별 조회수는 훨씬 낮음).
- 가이드 3개는 각각 1,500~1,800자로 분량이 작아 전면 재작성 비용도 크지
  않다.

**다음에 KO 가이드를 다시 손볼 때** 합쇼체/해요체 중 하나로 전체를
통일한다. 이번 조정에서 해요체 쪽으로 방향을 잡았으므로(About/Contact
신규 페이지도 해요체로 썼다) 특별한 이유가 없다면 해요체로 통일하는 쪽이
사이트 전체 톤과 맞는다.

## KO 전체 톤 기준 — JA 참조 사례 (2026-09-20 조사, 향후 코퍼스 톤 수정 시 참조)

세 언어 중 JA가 가장 정확한 톤을 쓰고 있다 — **전부 전언형**이다
(「〜とされる数字です」「〜として語られます」「〜といわれます」
「〜ことが多いです」). 판단의 주체가 "이 전통에서는/그렇게 전해진다"로
명시되고, 문장 자체가 단정을 피한다. KO는 같은 내용을 "〜입니다/
〜뜻합니다/〜나타냅니다"로 끝내 천사·우주·카르마의 작용을 관찰된 사실처럼
서술한다. 같은 숫자, 같은 주장을 KO/JA로 대조한 10개 사례:

| 숫자 | 일본어 (전언형) | 한국어 (단정형) |
|---|---|---|
| 111 | "현실의 사건으로 움직이기 시작하는 **타이밍인 경우가 많은 듯합니다**"(動き出すタイミングに来ていることが多いようです) | "'현실화의 게이트'가 **열렸음을 뜻합니다**" |
| 222 | "물밑에서 조율되고 있다는 것을 **전한다고 여겨집니다**"(伝えているとされます) | "천사들이 '…완벽하게 조율되고 있습니다'라고 **말하고 있습니다**"(직접화법 단정) |
| 333 | "보이지 않는 도움이 함께한다는 **메시지로 이야기되곤 합니다**"(メッセージとして語られることが多いです) | "승천한 마스터들이…**돕고 있다는 강력한 신호입니다**" |
| 444 | "튼튼한 토대 위에 서 있다는 **징조라고들 합니다**"(サインだといわれます) | "444는 천사의 보호가 **가장 강력한 숫자입니다**" |
| 555 | "큰 변화가 다가온다는 **징조라고들 합니다**"(サインだといわれます) | "555는…**가장 강력한 변화의 숫자입니다**"(변화 임박을 숫자 자체로 단정) |
| 666 | "소중한 것에서 멀어졌다는 **다정한 알아차림의 징조라고들 합니다**"(サインだといわれます) | "물질적인 것에 집착하고 있다는 **부드러운 경고입니다**" |
| 777 | "지금 걷는 길이 틀리지 않았다는 **확인의 징조라고들 합니다**"(サインだといわれます) | "걸어온 영적 길이 **정확히 옳았고**, 보상이 **다가오고 있습니다**" |
| 888 | "노력이 결실 맺을 시기가 다가온다는 **메시지라고들 합니다**"(メッセージだといわれます) | "카르마의 법칙에 의해…보상이 **돌아오고 있습니다**"(인과를 단정) |
| 999 | "인생의 중요한 한 장이 마무리돼간다는 **징조라고들 합니다**"(サインだといわれます) | "한 장이 완벽하게 **마무리되고 있음을 나타냅니다**" |
| 717 | "지금 길이 틀리지 않았다는…조용한 확인으로 **받아들여지는 경우가 많습니다**"(受け取られることが多いです, 수동태) | "…영적으로 올바른 방향이라는 **우주의 확인 도장입니다**"(우주가 실제로 도장을 찍었다는 단정) |

원문 출처: `angels-ja-core.ts`(KO는 `angels-core.ts`)의 111/222/333/444/
555/666/777/888/999/717 meaning 필드.

**향후 KO 전체(또는 부분) 톤 수정 시 이 표를 목표 톤의 기준으로 쓴다** —
JA를 번역하지 말고, "판단 주체를 명시하거나 빈도를 헤지하는" 그 원리만
이식할 것(다른 트랙들과 동일한 "축만 이식, 문장은 새로 쓴다" 원칙).

## 작업 이력

- KO에 없던 `/about`·`/contact` 신설(EN/JA는 이미 있었음). 번역이 아니라
  한국어로 새로 씀. 점술이 아니라 해석 자료라는 점 명시.
- `Layout.astro` 푸터에 사이트 소개·문의하기 링크 추가(기존엔
  개인정보처리방침만 있었음). `privacy.astro`의 문의 섹션도 `/contact`로
  연결.

  해석 형태("~로 해석돼요")로 완화하고, 각 가이드에 빈도착각/비과학적
  주장 아님을 밝히는 캐비앗 문단을 하나씩 추가(3개 전부 다른 문장으로 —
  3-gram 대조로 확인).

  About에 4번째로 추가하지 않음 — About에서는 예시 없이 원칙만 서술.
- 분량: 1,503→1,819 / 1,256→1,531 / 1,390→1,730자. EN(3,800~6,200자)
  수준으로 늘리지 않음(지시 범위 밖).
